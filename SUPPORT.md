# Support

For installation help, read [Installation](docs/INSTALL.md) or [安装说明](docs/INSTALL.zh-Hans.md).

- Bug or reproducible incorrect comparison: open a [bug report](https://github.com/qingtan-labs/ClariDiff/issues/new?template=bug_report.yml).
- Format or feature request: open a [feature request](https://github.com/qingtan-labs/ClariDiff/issues/new?template=feature_request.yml).
- Security issue: follow [SECURITY.md](SECURITY.md); do not post vulnerability details publicly.

When reporting a comparison problem, attach the smallest sanitized pair of files that reproduces it, the rule file if used, ClariDiff version, Mac model, and macOS version. Do not attach credentials or confidential data.

ClariDiff is a community open-source project. Support is best-effort and has no guaranteed response time.
