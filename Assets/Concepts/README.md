# ClariDiff icon concepts

These five directions were explored for ClariDiff. Concept 05 is the selected production icon; the others remain as design history.

## Naming direction

- Product name: **ClariDiff**
- Chinese display name: **明析**
- CLI: `claridiff`
- Positioning: *Compare anything. See what matters.*

The mark is deliberately format-neutral so it represents source code, structured data, and documents without implying JSON-only behavior.

## Concepts

### 01 — Structure Focus

- File: `Masters/icon-concept-01-structure-focus-1024.png`
- Metaphor: structured data converges on one meaningful delta.
- Strength: strongest brand symbol and best small-size recognition.
- Trade-off: curly braces make it JSON-first.

Prompt:

> Create a production-quality macOS application icon master, 1024x1024 PNG, for a global developer tool that compares JSON and structured data by meaning rather than lines. CONCEPT: STRUCTURE FOCUS. A premium rounded-square macOS icon with a deep midnight-indigo surface. In the center, two bold mirrored curly-brace forms act like an aperture, focusing inward on a single small warm amber diamond that represents the one meaningful change. Behind them, only three short cyan data bars on each side, perfectly ordered and subtle, suggesting structured objects. The composition must read instantly at 16–32 px: one silhouette, one focal change, minimal shapes. STYLE: modern native macOS, precise geometric construction, restrained soft depth, subtle material lighting, crisp edges, generous safe margin, professional developer-tool identity. Sophisticated indigo, cyan and amber palette. No text, no letters, no numbers, no logos, no magnifying glass, no globe, no database cylinder, no circuit board, no arrows. No mockup, no device, no surrounding scene. Transparent outside the rounded-square icon. Front-facing orthographic composition.

### 02 — Semantic Lens

- File: `Masters/icon-concept-02-semantic-lens-1024.png`
- Metaphor: raw noise resolves into an understood data tree.
- Strength: expresses semantic understanding most directly.
- Trade-off: more detail is lost at menu-bar scale.

Prompt:

> Create a production-quality macOS application icon master, 1024x1024 PNG, for a global developer tool that reveals semantic differences in JSON and structured data. CONCEPT: SEMANTIC LENS. A premium rounded-square macOS icon with a dark blue-violet surface. A large elegant circular glass lens is integrated into the icon, not a generic search symbol: outside the lens are a few softly blurred and misordered pale data blocks; inside the lens the same blocks resolve into a clean branching structure, with exactly one small amber node glowing as the meaningful difference. The lens handle is omitted; use a complete optical disc so it feels like interpretation and clarity, not search. Strong single silhouette and clear visual hierarchy at 16–32 px. STYLE: native macOS, subtle translucent glass, controlled highlights, crisp geometric structure, restrained depth, generous safe margin, globally legible, premium developer tool. Indigo, violet, cool cyan, one amber accent. No text, no letters, no numbers, no braces, no arrows, no globe, no database, no circuit/network imagery, no mockup or device. Transparent outside the rounded-square icon. Front-facing orthographic composition.

### 03 — Noise Filter

- File: `Masters/icon-concept-03-noise-filter-1024.png`
- Metaphor: many irrelevant changes enter; one true change remains.
- Strength: most distinctive expression of the product promise.
- Trade-off: weaker connection to JSON without supporting copy.

Prompt:

> Create a production-quality macOS application icon master, 1024x1024 PNG, for a global developer tool that filters meaningless changes from structured data and leaves only real changes. CONCEPT: NOISE FILTER. A premium rounded-square macOS icon with a charcoal-to-deep-teal surface. On the upper half, several small translucent structured tiles and dots flow downward into a beautifully simplified geometric sieve/prism. Most dissolve into faint particles as ignored noise; one distinct warm golden diamond exits cleanly below as the only meaningful change. Use a centered, iconic silhouette with very few elements and excellent readability at 16–32 px. It must feel analytical and precise, not like a kitchen funnel. STYLE: modern native macOS, refined material depth, soft controlled lighting, crisp geometry, spacious composition, professional data-tool identity. Charcoal, aqua/teal and gold. No text, no letters, no numbers, no braces, no magnifying glass, no arrows, no globe, no database cylinder, no circuit board, no mockup or device. Transparent outside the rounded-square icon. Front-facing orthographic composition.

### 04 — Precision Alignment

- File: `Masters/icon-concept-04-precision-align-1024.png`
- Metaphor: two structured datasets align while the real delta remains visible.
- Strength: clearest comparison metaphor and excellent small-size recognition.
- Trade-off: feels more functional and less ownable than concept 01.

Prompt:

> Create a production-quality macOS application icon master, 1024x1024 PNG, for a global developer tool that precisely aligns two structured datasets and highlights the true difference. CONCEPT: PRECISION ALIGNMENT. A premium rounded-square macOS icon with a deep slate-blue surface. Two compact vertical arrays of rounded data cells sit left and right, initially offset at their outer edges but snapping into exact alignment toward a thin luminous central axis. Most paired cells share cool mint-blue color and align perfectly; exactly one pair at the center differs, represented by a single coral-amber diamond-shaped cell. The visual should communicate comparison, matching, and one true delta without arrows. Strong symmetrical silhouette, very few cells, unmistakable at 16–32 px. STYLE: native macOS, elegant geometric construction, restrained depth, crisp edges, subtle dimensional lighting, generous safe margin, serious global developer-tool branding. Slate, blue, mint, one coral-amber accent. No text, no letters, no numbers, no braces, no magnifying glass, no arrows, no globe, no database, no circuit/network imagery, no mockup or device. Transparent outside the rounded-square icon. Front-facing orthographic composition.

### 05 — Universal Compare

- File: `Masters/icon-concept-05-universal-compare-1024.png`
- Metaphor: two format-neutral content files are aligned and their one meaningful difference is highlighted.
- Strength: immediately reads as comparison without implying JSON, source code, tables, or prose exclusively.
- Trade-off: the browser-toolbar variant should remove the internal grid at 16 px.

Prompt:

> Create a production-quality, format-agnostic comparison icon for ClariDiff, a tool that compares code, structured data, documents, and other content by meaning. Two clearly recognizable universal content sheets are shown side by side, slightly angled inward like an open comparison workspace. Each sheet contains the same simple combination of horizontal content lines and a small grid block, so they can represent code, data, or prose without favoring any one format. Most content aligns identically across both sheets. At one matching row, the left sheet has a short muted coral segment and the right sheet has a longer warm amber segment, both enclosed by one shared luminous comparison highlight spanning the gap. The single highlighted row must instantly communicate “these two files are being compared and this is the meaningful difference.” Premium rounded-square macOS/browser application icon, front-facing, centered, symmetrical, strong silhouette, generous safe margin. At 16–32 px it must still read as two files plus one highlighted difference. Use only two sheets, a few broad content marks, and one highlight. Modern native macOS icon, precise geometric 3D with restrained depth, crisp edges, controlled soft lighting, professional global developer/productivity tool. Deep midnight-indigo icon surface, cool cyan-blue sheets, restrained violet shadows, one warm amber/coral difference highlight. No text, no letters, no numbers, no JSON braces, no code symbols, no magnifying glass, no funnel, no arrows, no checkmarks, no globe, no database cylinder, no circuit board, no brand logos, no device mockup, no surrounding scene. Genuinely transparent outside the rounded-square icon.

## Recommendation

Use **05 — Universal Compare** as the lead candidate for the expanded multi-format product. It communicates comparison literally without tying the brand to JSON. Keep **04 — Precision Alignment** as the simplified, more abstract fallback.
