# Privacy

ClariDiff is local-first software. The macOS app and CLI compare files on your device and do not upload file contents, require an account, include analytics, or contact a ClariDiff service.

ClariDiff has no network feature. The only network access involved in normal use is initiated outside the app when you visit this GitHub repository or download a release.

Files selected in the app are read only for the active comparison. ClariDiff does not maintain a cloud copy or a comparison history. Exported reports are written only to the location you choose.

When filing a public issue, remove secrets and confidential content from screenshots, reports, rules, and sample files.

## 隐私说明

ClariDiff 是本地优先的软件。macOS 应用与 CLI 只在你的设备上读取并比较文件，不上传文件内容、不要求账号、不包含分析统计，也不会连接 ClariDiff 的在线服务。

应用本身没有网络功能。日常使用中涉及网络的操作，仅发生在你通过应用之外访问本 GitHub 仓库或下载 Release 时。

应用只为当前比较读取你选择的文件，不保存云端副本，也不维护比较历史。导出的报告只写入你主动选择的位置。

提交公开 Issue 前，请从截图、报告、规则和示例文件中移除密钥与机密内容。
