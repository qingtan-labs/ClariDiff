# ClariDiff 1.0.0 / 明析 1.0.0

**Compare anything. See what matters.** 这是 ClariDiff 的首个 macOS 正式版本：用一套本地、可复现的规则比较结构化数据、源代码和文档。

## Highlights / 主要能力

- JSON, JSONL/NDJSON, YAML, TOML, XML, and CSV structural comparison / 结构化比较
- Vue, React JSX/TSX, JavaScript/TypeScript, Svelte, Astro, HTML/CSS and more / 常用前端与通用源码比较
- TXT, Markdown, RTF, DOCX, and text-based PDF content-block comparison / 文档内容块比较
- Keyed and unordered arrays, ignored paths, numeric tolerance, and string normalization / 数组匹配、忽略路径、数值误差与字符串归一化
- Native SwiftUI app plus a Universal 2 CLI / 原生 macOS 应用与 Universal 2 CLI
- English and Simplified Chinese UI / 中英文界面
- Fully local: no account, analytics, cloud service, or file upload / 完全本地，无账号、无统计、无上传

## Downloads / 下载

- `ClariDiff-1.0.0-Universal.dmg` — macOS app for Apple silicon and Intel
- `claridiff-1.0.0-macos-universal` — standalone command-line tool
- `SHA256SUMS` — release checksums

## Installation note / 安装提示

This release is ad-hoc signed and not Apple-notarized. Verify `SHA256SUMS`, install the app, then Control-click it in Applications and choose **Open** on first launch. Never disable Gatekeeper.

此版本使用 ad-hoc 签名，尚未经过 Apple 公证。请先核对 `SHA256SUMS`；安装后首次运行时，在“应用程序”中按住 Control 点击 ClariDiff 并选择**打开**。请勿关闭 Gatekeeper。

Read the [English installation guide](https://github.com/qingtan-labs/ClariDiff/blob/v1.0.0/docs/INSTALL.md) or [中文安装说明](https://github.com/qingtan-labs/ClariDiff/blob/v1.0.0/docs/INSTALL.zh-Hans.md).

## Scope / 范围

ClariDiff 1.0.0 compares one pair of files at a time. Code comparison uses ordered content-block alignment rather than full language AST analysis. Scanned PDFs, encrypted documents, folders, images, and visual layout comparison are not included.

ClariDiff 1.0.0 每次比较一对文件。源码使用有序内容块对齐，暂非完整的语言 AST 分析；扫描 PDF、加密文档、文件夹、图片与视觉排版比较不在本版范围内。
